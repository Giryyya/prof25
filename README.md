## 1. Базовая настройка
1) Настройте имена устройств согласно топологии
&ensp; a. Используйте полное доменное имя
2) Сконфигурируйте адреса устройств на свое усмотрение.
   &ensp; 1. Для офиса HQ выделена сеть 192.168.11.0/24
   &ensp; 2. Для офиса DT выделена сеть 192.168.33.0/24
   &ensp; 3. Для туннелей между офисами выделена сеть 10.10.10.0/24
   &ensp; &ensp; i. Туннель должен вмещать минимально возможное количество адресов
   &ensp; 4. Данные сети необходимо разделить на подсети для каждого vlan.
   &ensp; &ensp; i. VLAN110 должна вмещать не более 64 адресов
   &ensp; &ensp; ii. VLAN220 должна вмещать не более 16 адресов
   &ensp; &ensp; iii. VLAN330 должна вмещать не более 8 адресов
3) На всех устройства (кроме FW-DT) создайте пользователя sshuser с паролем P@ssw0rd
   &ensp; 1. Пользователь sshuser должен иметь возможность запуска утилиты sudo без дополнительной аутентификации.
   &ensp; 2. На маршрутизаторах пользователь sshuser должен обладать максимальными привилегиями.
